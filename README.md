# Animated AI Website

An interactive, futuristic web experience featuring smooth scroll-driven canvas animations, dynamic 3D sequence rendering, responsive modern UI, and ambient visual effects.

## 🚀 Tech Stack

- **Vite** - Next Generation Frontend Tooling
- **HTML5 & CSS3** - Modern layout, flexbox/grid, custom glowing accents, glassmorphic UI
- **Vanilla JavaScript (ES6 Modules)** - Lerp-based smooth scroll frame interpolation, asset preloading, and real-time canvas rendering

## 🛠️ Local Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

4. **Preview production build:**
   ```bash
   npm run preview
   ```

## 🌐 Deploying to Vercel

1. Import this repository into **[Vercel](https://vercel.com/)**.
2. Vercel automatically detects the **Vite** framework preset:
   - **Build Command:** `vite build` (or `npm run build`)
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
3. Click **Deploy**.
